# Issue #128 — тексты и сценарии приёмки

## 1. Согласия

**Избранное** — «Сохранять материалы в избранное? Чтобы выбранные материалы были доступны в личном кабинете, нужно ваше отдельное согласие на сохранение списка избранного». Действия: «Разрешить» / «Не сейчас». Без согласия сохранение не происходит, доступ к контенту сохраняется.

**Публикация** — «Разрешить публикацию текста? Если вы решите опубликовать текст, он станет доступен другим пользователям после проверки модератором». Действия: «Разрешить» / «Не сейчас». Без согласия публикации нет, ввод не отправляется. Действительное согласие должно фиксироваться через backend с версией политики/временем, что **вне текущего UI-only scope**.

## 2. Ошибки

**Поля** — «Проверьте данные» + конкретные ошибки рядом с некорректными полями; значения остаются введёнными.

**Без сети** — «Нет подключения к интернету. Проверьте соединение и попробуйте снова. Введённые данные не пропали».

**Сервер** — «Сервис временно недоступен. Сейчас не удаётся выполнить действие. Попробуйте чуть позже».

## 3. Пустые списки

**Избранное** — «Здесь пока ничего нет». Ссылка «Перейти к материалам».

**Мероприятия** — «По выбранным фильтрам мероприятий нет». Кнопка «Сбросить фильтры». В демо после сброса виден специально маркированный фиктивный анонс.

**Модерация** — «В очереди нет новых материалов». Кнопка «Обновить очередь»; без ложной статистики и обещаний.

## 4. Недоступность интеграций

**SSO** — «Войти сейчас не удалось. Открытые материалы и кризисный раздел доступны без входа. Попробуйте позже». Кнопка повторения и ссылки на публичные разделы.

**Запись** — «Не удалось загрузить доступное время. Сейчас мы не можем получить данные из системы записи. Вы можете оставить заявку через действующую форму Психологической клиники СПбГУ». Форма: https://anketa.spbu.ru/psikhologicheskaya-klinika-konsultatsiya (сайт СПбГУ). Никаких кодов 500 или обещаний немедленного ответа.

## 5. Скрытый кризисный контакт

**Публичный** — только 112 и отсутствие просроченного номера/служебных объяснений. В продакшене перечень активных подтверждённых контактов поступает из справочника с контролем сроков и владельцем.

**Админ-предпросмотр** — «Контакт исключён из публичной выдачи», статус проверки и требуемое действие. В текущем макете показан фиктивный ID, без реального закрытого контакта.

## 6. Выход

**Подтверждение** — «Выйти из аккаунта? После выхода личные материалы и настройки станут недоступны до следующего входа. Открытые разделы останутся доступны». Кнопки «Да, выйти» / «Остаться в аккаунте».

**Результат** — «Вы вышли из аккаунта. Личные функции теперь недоступны. Вы можете продолжить просматривать открытые материалы без входа». Реальная инвалидация серверной сессии не входит в дизайн-макет.

## QA

1. Сценарии открываются напрямую по URL и через каталог; неизвестный slug даёт 404.
2. Все интерактивные элементы доступны через Tab/Enter/Space; фокус видимый.
3. Ошибки полей связаны с `aria-describedby` / `aria-invalid` и появляются рядом с вводом.
4. При отказе от согласия нет публикации/сохранения в UI.
5. На 360px контент не требует горизонтального скролла страницы (горизонтальный список сценариев допустим).
6. Просроченный контакт не отображается в публичной ветке, причина только в демонстрационном админ-предпросмотре.
7. Нет API-запросов к системам SSO и записи.
8. Нет реального запроса завершения сессии; это макет, а не авторизация.
9. Есть `prefers-reduced-motion`, семантические заголовки и читаемые сообщения.
10. Убедиться, что после переноса в общий репозиторий ссылки `/crisis` и `/psychoeducation` обслуживаются настоящими модулями.
