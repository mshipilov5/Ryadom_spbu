# Issue #152 — аудит API-контракта главной

**Результат по main от 2026-11-24: выявлена блокирующая нехватка endpoint.** В репозитории `api/openapi.yaml` описывает только психопросвет: `/api/v1/psychoeducation/materials`, `/{slug}` и `/filters`. Данных для приветственного блока, мероприятий, практик и состояния профиля там нет.

## Что необходимо согласовать с backend

1. Endpoint(ы) для блока «На сегодня»: поддерживающее сообщение, событие и практика.
2. Структуры ответов и примеры ошибок 400/401/404/500/503.
3. Гостевой доступ и способ безопасной передачи публичной информации.
4. Поля и формат времени мероприятия; отсутствие служебных полей и чувствительных данных.
5. Сохранение и обновление данных, требования к кэшу, тексты при сбое.

## Воспроизводимая проверка

```bash
python3 tools/audit_home_contract.py api/openapi.yaml
```

Код возврата `1` означает найденный незакрытый пробел в контракте, а не сбой скрипта. **Изменения OpenAPI не внесены**: это задача аудита, новые endpoint нужно согласовать с backend и владельцем продукта.
