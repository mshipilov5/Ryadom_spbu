### Создать 2 подзадачи:
A. Верстка страниц для компонента
B. Интеграция с API

### Задача верстки:
Definition-Of-Ready: Описан ожидаемый состав компонента
Definition-Of-Done: Готовы и согласованы страницы компонента (кроме интеграции с API)
Lifecycle: To-do → В работе → Аудит → (optional) Доработка → Done

### Задача реализации:
Definition-Of-Ready: Страницы готовы и согласованы, готов контракт API
Definition-Of-Done: Страницы интегрированы с API, проведено интеграционное тестирование
Lifecycle: To-do → В работе → Тестирование → (optional) Доработка → Done

---


## Definition of Ready:

-Понятна цель задачи и её связь с требованиями продукта.
- Назначен ответственный исполнитель.
- Описан ожидаемый результат.
- Критерии приёмки сформулированы проверяемо.
- Определены зависимости и внешние блокеры.
- Указаны необходимые технические ограничения при наличии таковых.
- Достаточно информации для оценки трудоёмкости.
- При необходимости приложены API-контракты, макеты, схемы и решения.
- Не осталось критических вопросов, препятствующих реализации.


## Definition of Done:
- Реализован весь согласованный объём задачи.
- Все критерии приёмки выполнены.
- Автоматические тесты написаны или обновлены в соответствии с характером изменений.
- Проверены ошибки и граничные сценарии.
- Нет известных блокирующих дефектов.
- Обновлена необходимая документация.
- Изменения интегрированы в целевую ветку по правилам репозитория.
- CI завершился успешно.
- Все обязательные требования безопасности выполнены.




## Дополнительные критерии Defenition of Done для Frontend
- Проверены состояния загрузки, ошибки, пустого результата и отсутствия доступа.
- Интерфейс адаптирован для мобильных устройств.
- Проверена клавиатурная навигация и видимость фокуса.
- Проверено соответствие API-контракту.
- Обработаны ошибки API и истечение пользовательской сессии.
- Нет известных блокирующих проблем доступности.
