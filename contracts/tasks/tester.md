### Тестирование контракта API

Definition-Of-Ready: Создан и задокументирован контракт
Definition-Of-Done: Контракт одобрен
Lifecycle: To-do → В работе → (optional) Ожидает исправления → Done

Задача тестировщика на данном этапе проверить:

- Предоставленных endpointов достаточно
- frontend способен составить запрос (имеет необходимые данные) и правильно обработать ответ
- Схемы предоставляют все необходимые данные и при этом не содержат лишних
- Документация составлена согласно правилам



### Аудит UI-only

Definition-Of-Ready: Страницы свёрстаны и к ним предоставлен доступ
Definition-Of-Done: Прототипы одобрены
Lifecycle: To-do → В работе → (optional) Ожидает исправления → Done

Задача тестировщика на данном этапе проверить:

- Вёрстка не ломается на разных экранах
- Ключевые элементы страниц легко заметны и достижимы
- Нет ошибок в работе интерактивных элементов
- Навигация по компоненту не вызывает сложностей у потенциального пользователя
- Страницы соответствуют ожидаемому виду компонента и userflow



### Тестирование API

Definition-Of-Ready: Логика API реализована
Definition-Of-Done: Ошибки при взаимодействии с API не выявлены
Lifecycle: To-do → В работе → (optional) Ожидает исправления → Done

Задача тестировщика на данном этапе проверить:

- Функциональность endpointа соответствует заявленному
- При ожидаемом поведении не возникает ошибок на стороне сервера (500)
- При edge-кейсах (при наличии) не возникает ошибок на стороне сервера (500)
- Ошибки клиента (400) правильно обрабатываются, ответы соответствуют ожидаемым
- При успешном ответе (200) действие действительно выполнено



### Тестирование фронтенда

Definition-Of-Ready: API и frontend реализованы и интегрированы между собой
Definition-Of-Done: Ошибок не выявлено
Lifecycle: To-do → В работе → (optional) Ожидает исправления → Done

Задача тестировщика на данном этапе проверить:

- Передаваемые данные с фронтенда соответствуют контрактам
- Вызываются правильные endpointы
- Ответы корректно обрабатываются
- Состояния интерфейса (если исполняется сохранение, пусть говорил, что сохранил)
- Сценарии после интеграции работают верно (после входа в учётку должно редирнуть на профиль/ нужную страницу)
