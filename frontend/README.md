# Рядом — дизайн нестандартных UI-состояний (Issue #128)

Интерактивные макеты для issue [#128](https://github.com/mshipilov5/Ryadom_spbu/issues/128): согласия, ошибки, пустые списки, недоступность SSO/системы записи, скрытие устаревших кризисных контактов и подтверждение выхода.

## Назначение

Это **UI-only дизайн-каталог** на моках, а не реализация auth, API, хранения согласий, проверки кризисных контактов или сетевого мониторинга. Все действия, кроме внешних ссылок и `tel:112`, меняют только локальное состояние экрана.

Стек: TypeScript, React 19, Next.js App Router 16, обычный CSS. Нет зависимости от `modules/education`, `modules/practices`, `modules/crisis`, модулей авторизации и SQLite. Существующий `api/openapi.yaml` не изменён.

## Автономный запуск

```bash
cd frontend
npm install
npm run dev
```

Главная страница переадресует на `/ui-states/consent-favorites`. Откройте `http://localhost:3000/ui-states` и переключайте сценарии в левом каталоге. Не нужен backend и база данных.

Перед PR: `npm run typecheck` и `npm run build`. Полная сборка в среде подготовки **не подтверждена** из-за отсутствия доступа к `registry.npmjs.org` (DNS EAI_AGAIN); проверен парсинг всех TypeScript/TSX-файлов.

## 12 адресов для проверки

| Сценарий | URL | Что нажать или проверить |
|---|---|---|

Остальные `frontend/*` файлы автономного архива — **демо-каркас** Next.js для запуска в отдельной ветке от `main`, где пока нет frontend. Две временные страницы `/psychoeducation` и `/crisis` существуют исключительно для демонстрации навигации. В минимальный PR-архив они **не входят**.

## Безопасность и продуктовые ограничения

- Согласия не сохраняются и не передаются в API. Кнопка «Не сейчас» не блокирует доступ к открытым материалам.
- При ошибках не показываются внутренние коды сервера и не очищаются введённые данные.
- SSO и запись не эмулируют успешную авторизацию/подачу заявки.
- В сценарии `contact-expired` номер, не прошедший проверку, **не показывается публичному пользователю**. В макете присутствует `112`, без вымышленных «проверенных» телефонов.
- Режим «администратор» — доступный всем переключатель **только для дизайн-превью**, не система прав. Перед реальной интеграцией сведения справочника должны передаваться только авторизованным администраторам.
- Кнопка выхода только меняет локальный вид; настоящую серверную сессию нужно закрывать отдельным API-вызовом.
- Для внешней записи используется подтверждённая официальная форма СПбГУ: https://anketa.spbu.ru/psikhologicheskaya-klinika-konsultatsiya . Актуальность ссылки необходимо периодически контролировать перед внедрением.
